# Portfolio knowledge base template

Copy a folder to `~/PortfolioKB/<portfolio>/` (git init it). Agents read it through an MCP
filesystem server; humans edit it in any editor (it opens fine as an Obsidian vault).

Per portfolio: `goals.md` (quarter goals + KPIs), `decisions.md` (dated, one line each + why),
`context.md` (what the agents must know), `playbooks/` (how work is done).
No account numbers, tax IDs or statements — ever.
